# 真机验收表

截至 2026-10-15，本机未发现目标键盘。以下各项均为待验收，不能由模拟设备或离线测试勾选。

记录：键盘完整型号、布局、固件版本、USB 连接方式、H-hub 版本 / Chrome 或 Edge 版本。

1. 在官方驱动读取并记录当前参数，保留现有配置。关闭占用设备的官方页面 / 奥创程序。
2. 连接本插件。确认型号为 ACE HFX、VID/PID 为 0B05:1B7E，固件和当前板载配置正确。进入页面或切换按键后，原设置应保持不变。
3. 先将单个 W 键触发行程调到较温和的 1.2 mm，读取应为 1.2；再到官方软件读取交叉确认，然后恢复原值。全键参数另行验证，检查原有单键覆盖行为。
4. 顶部 / 底部死区分别用不同值测试，确认没有互换。恢复原值。
5. RT 总开关、W 单键对称灵敏度逐项验证。检查物理 RT/N 拨杆覆盖行为。再验证 WASD 批量修改。连续 RT 的实际行为单独确认。
6. 用单个低影响按键改键并回读，确认原触发行程没有被改动。恢复此键。
7. Speed Tap 在保留现有其他配对的前提下添加 / 删除一组配对，并核对设备实际输入行为。恢复原配置。
8. 静态、呼吸、色彩循环分别验证颜色、速度与亮度。确认读取配置和实际显示一致，并恢复原灯效。
9. 分别设置 1000 / 8000 Hz，回读且在官方软件确认。不要只依靠此插件界面推断实际扫描频率。
10. 用户明确点击保存后拔掉 USB、重新插入，再读取每项参数，验证断电保留。没有此步骤就不标注“保存持久化已验证”。
11. 在读取和写入进行中断开设备，页面应报错并要求重连。晚到的回复不能使下一次写入被误报成功。设备拒绝命令时不得循环重试。
12. 在 H-hub 中切换页面、关闭页面、切换明暗主题和减少动画，检查句柄释放和界面状态；再验证独立 Chrome / Edge 运行。

若中途任一项出现不一致，保留诊断，停止该项验收。WASD 批量写入失败之前的按键可能已经改变，需逐键读取确认。验收记录应明确“写入 ACK”“设备回读”“实际行为”“断电保留”各自的结果。
