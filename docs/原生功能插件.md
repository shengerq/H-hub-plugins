# Hhub 原生功能插件

这两个插件使用 Hhub 1.0.9 及以上版本已有的原生页面和后台服务。插件包登记功能、来源和权限，不重复打包音频引擎，也不是独立的 Windows 程序或手机 APK。

| 插件 | ID | 版本 | 安装后入口 |
| --- | --- | --- | --- |
| 通用 EQ | `eq` | 1.0.3 | 插件市场或插件管理中的“打开”，进入通用 EQ |
| 手机遥控 | `phone` | 1.0.9 | 插件市场或插件管理中的“打开”，进入手机遥控 |

从 GitHub 插件库同步后安装，或手动导入根目录的 `.hhub` 文件。宿主不再自动注册或随安装目录分发第二个本地插件库。EQ 与手机遥控默认不安装；未安装时不显示侧边栏入口，安装后才显示。首次安装仅登记清单和入口，不自动启用 EQ 处理或手机服务。手机遥控需要在设置中启用功能，再在原生页面明确开启服务、配对手机并授予权限；安装插件包不会自动授予手机权限。卸载会关闭服务、移除入口并清理本插件配置；手机遥控还会撤销配对、删除本机证书和属于当前程序的防火墙规则。升级插件保留设置。

EQ 的虚拟音频驱动仍通过 EQ 设置中的独立安装入口安装。无需驱动的配置编辑及预设浏览不受影响。FxSound 预设和 DSP 实现由 Hhub 宿主提供，更新宿主以更新实现；仅替换此插件清单不会替换 DSP 二进制。

应用插件的 compatibility.scope 为 tool。手机遥控插件本身不是某一型号外设的手机 UI，因此 mobileUi 为 false；外设手机界面的兼容性仍由相应设备插件声明。

## Windows 设置

[安装包](../Hhub-Windows-Settings-1.0.9.hhub)的 ID 为 `windows`，版本 1.0.9。未安装不显示入口，也不能调用宿主 Windows 设置接口。安装后复用原生设置页和按需 Worker，保留单按钮加载与延迟反馈。卸载清理回退记录与临时请求，不重置已应用的 Windows 设置。
