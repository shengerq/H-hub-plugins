# 应用插件

| 分类 | 当前插件 |
| --- | --- |
| 实验型应用 | 暂无 |
| 测试型应用 | [H hub 开发者工具 0.5.2](../../Hhub-Developer-Tools-0.5.2.hhub) |
| 其他 | 暂无 |

实验型应用用于尝试新功能或交互；测试型应用用于调试、检测、测试与验证；其他用于不属于前两类的应用扩展。开发者工具包含协议调试和报文测试工作台，因此归入测试型应用。

提交时在根目录 `index.json` 填写 `group: "application"`，并选择 `category: "experimental" / "testing" / "other"`。包文件保留在仓库根目录，由统一索引分发。

应用插件不参与外设型号及固件匹配；应用可以读取设备或提供调试功能，但不会因此被当作某一型号的外设驱动插件。
