外设插件按设备名称、硬件识别码及固件版本匹配同类设备。分类本身不能证明设备兼容或通过验收。

提交时在根目录 `index.json` 填写 `group: "peripheral"`，并选择 `category: "mouse" / "keyboard" / "headset" / "gamepad" / "other"`。包文件保留在仓库根目录，由统一索引分发。
