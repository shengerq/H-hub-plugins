## 虚拟鼠标体验

[下载体验插件](../../../Hhub-OpenMouse-Virtual-Lab-0.1.0.hhub) · [离线体验页面源文件](./virtual-experience.html)

体验包位于现有“应用插件 → 实验型应用”分类。它运行真实 VAXEE / MCHOSE 协议与软件虚拟设备，支持 DPI、回报率、传感器开关、拔插和失败模拟。仅申请离线页面权限，不访问真实鼠标。下载 HTML 后在本地浏览器打开即可体验；GitHub 文件页面本身不会执行 HTML。
