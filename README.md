# Hhub 外设插件库

外设插件按类型直接放在仓库根目录，共 331 个索引条目。

- [鼠标](./鼠标/)：330 个插件。
- [键盘](./键盘/)：1 个插件。
- [音频](./音频/)
- [手柄](./手柄/)
- [其他](./其他/)

型号、协议和验证状态以各插件声明为准；协议或虚拟设备测试不代表实机验收。

主程序通过根目录的 `index.json` 同步插件。插件包内容、版本及 SHA-256 保持不变，仅调整目录与索引路径。
