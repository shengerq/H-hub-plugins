## 使用

1. 按分类和品牌找到所需型号，下载对应 `.hhub` 文件。
2. 在 H hub 的插件管理中导入，核对名称、版本和权限后启用。
3. 外设功能以具体型号、协议和插件声明为准。

需要全部插件时，可在 GitHub 使用 **Code → Download ZIP**，解压后按现有目录选择。

## Hhub 1.0.10 可选功能插件

通用 EQ、Windows 设置、手机遥控独立下载，基础安装包不包含这三个插件。请先升级到 Hhub 1.0.10；旧宿主不支持组件包，会拒绝安装。

- Windows 设置 1.0.10 包含设置执行组件，安装后逐项读取和回传系统状态。
- 手机遥控 1.0.10 包含服务程序及手机网页，保留已有配对资料。
- 通用 EQ 1.0.4 包含 FxSound 官方签名虚拟音频驱动的独立安装程序。安装插件后，如未检测到驱动，会提示安装。Windows 需要管理员授权，部分电脑可能需要重启；可选择稍后，继续编辑和保存曲线。请先退出 FxSound。Hhub 仅处理绑定应用，不把所有物理输出设备改为 EQ 输出。

组件仅在确认安装后解包，不保存在 UI 的常驻状态里；卸载插件时清理其文件。EQ 界面与宿主一起升级，插件负责可选功能与驱动组件。

驱动保持原始 INF、SYS 和微软签名目录文件，安装程序校验签名后安装。驱动源代码与许可见 [FxSound driver](https://github.com/fxsound2/fxsound-driver)；包内保留 AGPL 与 Microsoft Limited Public License 文本。Hhub 安装包装及本次宿主实现源码见 [资料源码](./资料源码/)。
