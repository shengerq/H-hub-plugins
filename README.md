# H hub 插件库

用于分发 H hub 外设插件和开发者工具。本次整理包含 **0.5.1** 版本的两个插件、插件库索引、安装与开发说明，以及用户提供的三个原始 ZIP 包。

本仓库是插件分发仓库，**不包含 H hub 主程序或完整主程序源码**。`.hhub` 文件是插件包，需通过兼容的 H hub 插件管理导入；不能当作独立 Windows 程序运行。

主体程序及源码：[shengerq/H-hub](https://github.com/shengerq/H-hub)。本库 index.json 是主体程序的默认插件源。新发布的 **0.5.2** 包补充了同类设备匹配契约、固件列表和手机 UI 声明；0.5.1 历史包保留。固件及实机证据尚未补全，当前没有已验证记录。

## 安装方式一：导入插件包

1. 准备支持这些插件的新版 H hub。包声明的插件 API 版本为 `1.0`；附件没有提供可核实的主程序最低版本号；当前主程序可从 [H hub 1.0.3 发行页面](https://github.com/shengerq/H-hub/releases/tag/v1.0.3) 下载。
2. 点击上面的 `.hhub` 文件，在 GitHub 文件页面下载原始文件。不要把网页另存为 HTML，也不要修改插件扩展名。
3. 在 H hub 的插件管理中导入下载的 `.hhub` 文件。
4. 核对插件名称、ID、作者、版本及申请权限，然后安装并启用。
5. 鼠标插件：连接 VT3S MAX 的 2.4 GHz 接收器，从首页设备详情进入设置页。
6. 开发者工具：启用后从侧栏“开发者”进入工作台。

如果下载的是 ZIP，请先解压，再导入其中的 `.hhub`。主程序需另外准备。

## 安装方式二：同步 GitHub 插件库

部署时将 `index.json` 和两个 `.hhub` 文件放在同一分支的根目录；原附件按 `main` 分支组织。**不能只上传三个 ZIP**，否则软件无法按根目录索引获取插件包。

本插件库地址为 [shengerq/H-hub-plugins](https://github.com/shengerq/H-hub-plugins)。在 H hub 插件管理中填写 `shengerq/H-hub-plugins`，然后点击“同步插件库”。索引直链为 [index.json](https://raw.githubusercontent.com/shengerq/H-hub-plugins/main/index.json)。

原附件说明：软件支持按名称、设备型号、作者及标签搜索；同步后需由用户确认安装；下载时核对摘要及身份字段；断网保留最近成功同步的清单。这些主程序行为未在本次整理中运行验证。私有仓库是否能被主程序读取，需确认主程序是否支持 GitHub 身份验证。

## 雷柏 VT3S MAX 插件

| 项目 | 内容 |
| --- | --- |
| 插件 ID | `hhub.rapoo-vt3s-max` |
| 作者 / 版本 | `H hub` / `0.5.1` |
| 声明权限 | 离线插件页面、USB HID 配置 |
| 宿主要求 | `hhub`，API `1.0`，`host-only`，不支持独立运行 |
| 包中设备匹配 | VID `24AE`、PID `1421`、Usage Page `FF00` |

根据包内容和附件说明，插件提供以下界面与能力：

- 最多七档 DPI 设置、档位管理和切换。
- 按键功能映射，包括常用鼠标功能、键盘字符及媒体操作。
- 回报率、性能模式、无线策略、按键扫描率等设置页面。
- 静默高度、传感器角度、按键防抖等设置页面。
- 参数写入后的回读校验、参数同步，以及电量与连接状态上报逻辑。
- 原厂固件下载入口。

实际可用参数取决于型号、固件、连接方式和宿主支持，不能据此推断其他雷柏型号、其他硬件批次、有线或蓝牙模式也兼容。

**功能边界：宏实体执行尚未验收；固件入口仅下载文件，不进行刷写。** 原附件提到真机测试，本次仅检查包结构和摘要，没有连接鼠标重做硬件验收。

## 开发者工具

| 项目 | 内容 |
| --- | --- |
| 插件 ID | `hhub.developer-tools` |
| 作者 / 版本 | `H hub` / `0.5.1` |
| 插件 API | `1.0` |
| 声明权限 | 离线插件页面、用户选择的抓包文件、项目文件导入与导出、USB HID 配置 |

工作台包含四类外设开发环境，支持控件定义与自定义 HTML 预览、项目保存与恢复、抓包导入与差异比较、控件到报文字节的绑定、编码预览及开发插件导出。鼠标开发界面还包含连接方式、VID/PID、固件与协议来源记录，并内嵌雷柏页面参考。

通用工作台生成的页面和报文预览不能证明硬件已接受配置。导出的开发插件仍需实现设备 Worker、权限接口、回读和断线恢复，并完成真机验证。内嵌雷柏页面声明了 USB HID 配置能力，使用前应核对权限和连接设备。

详细流程见 [开发指南](./docs/开发指南.md)。

## 文件结构与维护

```text
H-hub-plugins/
├── README.md
├── index.json
├── Hhub-Developer-Tools-0.5.1.hhub
├── Hhub-Rapoo-VT3S-MAX-0.5.1.hhub
├── SHA256SUMS.txt
├── docs/
│   ├── 开发指南.md
│   ├── 发布与故障排查.md
│   └── 图片来源.md
├── scripts/
│   └── verify-index.ps1
└── original-packages/
    └── 三个原始 ZIP 文件
```

`index.json` 使用 `schemaVersion: 1`，每项包含 `id`、`name`、`author`、`version`、`description`、`kind`、`tags`、`packageUrl` 和 `sha256`。当前 `packageUrl` 为相对于索引文件的包文件名。修改包内容后必须更新 SHA-256；插件 ID、名称、作者和版本应与包一致。

运行 `pwsh -File ./scripts/verify-index.ps1` 检查索引与包内容。该脚本只检查，不修改文件，也不访问设备。

原上传包内的 `build-index.ps1` 依赖上级工程中的 `dist` 和 `app` 目录，无法直接在这个独立分发仓库中使用；原 `publish-repository.ps1` 也会调用它。因此这两个原脚本仅保留在原 ZIP 中，未作为本仓库的可用发布脚本。发布步骤见 [发布与故障排查](./docs/发布与故障排查.md)。
