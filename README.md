## 安装与更新

1. [安装 Hhub 主程序](https://github.com/shengerq/H-hub/releases/latest)。
2. 打开主程序的插件市场，选择外设插件库并同步。
3. 找到对应品牌和型号，查看兼容要求及权限后安装。

也可以从本仓库下载 `.hhub` 插件包，再通过主程序导入。插件版本、适配硬件和最低主程序要求以包内声明为准。

## 兼容性与验证状态

相近型号不代表协议相同。安装前请核对设备型号和硬件标识，并查看插件声明的验证状态。协议实现、虚拟设备测试通过不等于真机验证完成。
